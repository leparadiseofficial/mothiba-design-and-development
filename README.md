# MOTHIBA DESIGN AND DEVELOPMENT SERVICES

A premium, responsive business website using a black, gold, and silver visual identity with a custom house emblem.

## Files

- `index.html` — page content and enquiry form
- `style.css` — responsive layout, colours, typography, and styling
- `script.js` — mobile navigation and enquiry form behaviour

## Preview locally

Open `index.html` in a modern browser. The Google Fonts connection requires internet access; system font fallbacks are included.

## Publish with GitHub Pages

1. Create a public GitHub repository named `mothiba-design-and-development`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The project URL will normally be:
   `https://YOUR-GITHUB-USERNAME.github.io/mothiba-design-and-development/`
